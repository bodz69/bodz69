## About me

- 🤖 Developing mobile robots, AGVs and robotic-arm simulations
- 📡 Working with UWB, wheel odometry, IMU and Kalman/EKF sensor fusion
- ⚙️ Building embedded control systems with ESP32 and STM32
- 🧭 Exploring path planning, obstacle avoidance and multi-robot coordination
- 👁️ Applying computer vision and deep learning to real-world recognition tasks
- 🛠️ Interested in projects that connect simulation with physical hardware
